Theory & Working of ID3 / Decision Trees
What is a Decision Tree?

A Decision Tree is a supervised machine-learning model that predicts a target by learning simple decision rules from features. Each internal node tests a feature, each branch represents an outcome of that test, and each leaf gives a prediction.

ID3 (Iterative Dichotomiser 3) by Ross Quinlan (1986) builds the tree top-down, greedily choosing at each node the feature that maximises Information Gain.

Key Terminology
  • Root node – top-most node; best splitting feature
  • Internal node – a feature being tested
  • Branch – outcome of a feature test
  • Leaf node – terminal node carrying a class label
  • Pure node – all examples have the same class (entropy = 0)
  • Impure node – mixed classes; needs further splitting
Shannon Entropy — Measuring Impurity

Entropy quantifies the uncertainty or impurity in a set of examples. It comes from information theory (Claude Shannon, 1948).

H(S) = −∑ p_i · log₂(p_i) For binary classification (Yes / No): H(S) = −(p_yes · log₂ p_yes) − (p_no · log₂ p_no) Where: S = current dataset or subset p_yes = proportion of positive examples (yes / total) p_no = proportion of negative examples (no / total) log₂ = logarithm base 2 (result in bits)
H = 0 (Pure)
0.000
All examples same class — perfect split
H = 0.971 (Mixed)
0.971
2 yes, 3 no (or 3 yes, 2 no) — noisy
H = 1.0 (Maximum)
1.000
Equal split (50 / 50) — maximum uncertainty
Worked Example — Root Entropy (9 Yes, 5 No, Total 14):
H(S) = −(9/14)·log₂(9/14) − (5/14)·log₂(5/14)
     = −(0.643)·(−0.637) − (0.357)·(−1.485)
     = 0.410 + 0.530 = 0.940
Information Gain — Choosing the Best Split

Information Gain measures how much an attribute reduces entropy in the dataset. The attribute with the highest IG is chosen as the splitting criterion.

IG(S, A) = H(S) − H(S | A) Where the weighted (conditional) entropy is: H(S | A) = ∑ (|S_v| / |S|) · H(S_v) v∈values(A) S_v = subset of S where attribute A = v |S_v| = number of examples where A = v |S| = total examples in current set
Worked Example — IG for Outlook (root level):

Subsets:
 Sunny: 5 rows (2 yes, 3 no) → H = 0.971
 Overcast: 4 rows (4 yes, 0 no) → H = 0.000  ← pure!
 Rain: 5 rows (3 yes, 2 no) → H = 0.971

Weighted Entropy:
 H(S|Outlook) = (5/14)·0.971 + (4/14)·0.000 + (5/14)·0.971
             = 0.347 + 0 + 0.347 = 0.693

Information Gain:
 IG(S, Outlook) = 0.940 − 0.693 = 0.246

ID3 Algorithm — Pseudocode
function ID3(S, Features, Target): // Base cases if all examples in S have the same Target class: return LeafNode(class) if Features is empty: return LeafNode(majority_class(S)) // Recursive case A ← argmax_{f ∈ Features} IG(S, f) // best feature T ← new internal node labelled A for each value v of A: S_v ← { x ∈ S | x.A = v } if S_v is empty: add leaf with majority_class(S) to T else: add branch ID3(S_v, Features − {A}, Target) to T return T
Stopping Conditions
  • All examples → same class (leaf)
  • No more features to split on (leaf with majority class)
  • Subset is empty (leaf with parent majority)
Complexity
  • Time: O(|S| · |F| · depth)
  • Space: O(|F| · depth)
  • Greedy — no backtracking
  • Finds locally optimal split at each step

Advantages
  • Highly interpretable — easy to visualise and explain
  • Handles both categorical and numerical data
  • No normalisation or scaling required
  • Can handle missing values (with modifications)
  • Non-linear boundaries possible
  • Fast inference — O(depth) per prediction
Disadvantages
  • Prone to overfitting on training data
  • High variance — small data changes → different trees
  • Biased toward features with many values
  • Cannot model XOR / parity patterns efficiently
  • Greedy split — may miss globally optimal tree
  • Single tree less accurate than ensembles (Random Forest)
Extensions of ID3:
C4.5 — handles continuous features, missing values, uses Gain Ratio
CART — binary splits, uses Gini impurity, produces binary trees
Random Forest — ensemble of decision trees for much higher accuracy
